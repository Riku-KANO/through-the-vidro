# src/core 変更記録

`src/core/` は姉妹作「泡沫回廊」と共通の部品です。ディレクトリをまたいで参照せず、先に変更した側から
もう一方へまとめてコピーします。コピーしたら、受け取った側の VERSION をこの版に合わせます。

## 0.2.0（提案）— 2026-10-21（S-09 音の基礎）

`src/core/VERSION` は S-09 の書き込み範囲の外なので未更新。統合時に 0.2.0 へ上げる（他のスライスの core 変更と合わせて採番し直してよい）。
すべて Web Audio API だけで作り、依存パッケージは足していない。ゲーム固有の規則は持たない（ぽぺんの4種の割り当てだけは例外で、下記）。

- `audio/scale.ts`: 音階の計算（平均律 A4=440Hz、`Scale` 型、D メジャー・ペンタトニック D E F# A B、最寄りの音への吸着、音階の度数での移動）と、
  大きさから音程を選ぶ規則 `pitchForSize`（f ∝ 1/大きさ = 大きさが倍で1オクターブ下、D2〜D7 に収めて必ず音階の音）
- `audio/mix.ts`: 音量の4系統（全体 / 音楽 / 効果音 / 環境音）と、スライダー位置→ゲインの曲線（2乗。半分で約 -12dB）
- `audio/engine.ts`: `AudioEngine` — AudioContext を最初のユーザー操作で開始し、中断後の操作で再開する（自動再生が許される環境でも作成時は止めておく）。
  バス（音楽/効果音/環境音）→ 全体 → リミッター、各バスから残響への送り、HRTF の `Emitter`（PannerNode）、聞き手の姿勢、同時発音数の上限。
  止まっている間は位置の自動化を積まずに最新値だけを保持し、再開時に反映（毎フレーム呼んでも確保なし）
- `audio/reverb.ts`: 合成インパルス応答（指数減衰するステレオのノイズ、時間とともに高域が先に減衰、初期反射、プリディレイ、エネルギー正規化）と、
  2つの ConvolverNode をクロスフェードして部屋を切り替える `RoomReverb`。汎用のプリセット `smallRoom`（T60 0.6秒）/ `largeDome`（T60 4.2秒）
- `audio/glass.ts`: ガラスの音のモード合成（Rayleigh の薄い殻の式による非整数倍の倍音 1 : 2.83 : 5.42 : 8.77、基音の対の分裂によるうなり）。
  強さ3段階（触れる/叩く/玉が当たる）× 大きさ（大きいほど長く鳴る）、毎回の揺らぎ。純粋な設計関数とノードへの書き出しを分離
- `audio/popen.ts`: 手の玉の「ぽぺん」（薄いガラスの底がはじける短い二音）。4種（覗く/置く/拾う/震える）の音型は**ゲーム固有の割り当て**で、
  M1 で `src/audio/` に移す候補。泡沫回廊にコピーする場合は音型の表ごと差し替えてよい
- `audio/play.ts`: 生演奏の補助（毎回新しい乱数の種で設計 → 発音枠の確保 → Emitter かバスへ）
- `audio/offline.ts`: OfflineAudioContext での書き出し（センサー用・将来の焼き込み用）。描画中は組んだグラフへの参照を保持する
- `audio/analysis.ts`: 書き出した音の計測（RMS、ピーク、FFT による基音推定、Schroeder 積分による T60、スペクトル重心、相関）
- 注意（Chrome）: JS から参照の切れたノードは、音源が鳴り終わった後の GC で切り離され、残響の尾が途中で切れることがある。
  尾を持つノード（Convolver など）は鳴り終わるまで参照を持つこと（`AudioEngine` は保持している）

## 0.1.0 — 2026-10-21（S-00）

- `renderer.ts`: WebGPURenderer の生成（WebGL2 への自動切替、AgX、sRGB、描画解像度の倍率）
- `quality.ts`: 品質プリセット 低・中・高（設計書「品質プリセット」の表）
- `bench.ts`: フレーム時間の統計（平均・p50/p95/p99・最大）と描画予算の判定
- `params.ts`: URL スイッチ（scene / bench / warmup / quality / webgl / stats）
- `scene.ts`: 検証用シーンの契約（SceneFactory / SandboxScene / SceneContext）
