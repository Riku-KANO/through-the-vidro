## 範囲の読み（paths の中だが、書かれた用途より広いもの・範囲外に触れなかった所）

- `src/game/prologue/room.ts`（「設定の適用の配線だけ」）: 22 行足し 3 行書き換えた。PrologueRoom と BuiltRoom の型に
  `applySettings`、殻に設定を覚える `let settings` と `applySettings`（組み上がった部屋に渡す。組み上がる前の設定は `prepare` で渡す）、
  `standingFov` を設定の視野角を返す getter に、組み上がった部屋の `applySettings`（入力の覗く・感度・反転、体の視野角、操作表示の
  言葉）、`const text` を `let text` に。ほかの行は動かしていない。並行の S-44 とは、PrologueRoom の型・殻の object・BuiltRoom の
  型と object の末尾の近くで重なりうる（どれも足しただけなので、両方を残せば解ける）。
- `src/main.ts`: 品質の口（`QualityPort` をシーンの文脈に `qualityPort` として渡す、`attach`）、保存した品質で始める、設定の選択で
  governor を作り直す、その場の切り替え、ポーズ中は governor に渡さない（`idle`）、probe の 4 つ（`qualityChoice`・`qualityOrigin`・
  `qualitySwitchesInPlace`・`idleFrames`）。main.ts が `src/ui/settings/settings-store.ts` の `readSavedQuality` を読む（殻がゲームの
  設定の保存先を知る。シーンの一覧では読まない）。
