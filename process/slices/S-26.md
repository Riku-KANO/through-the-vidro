## 作ったもの

### 焼き込みの段（受け入れ条件1）

`pnpm assets` の流れ（`blender/scripts/pipeline.py`）: 命名の検査 → 三角形の数 → 原点 → **2つ目の UV**（`common/uv.py`、透過でない物）→
**焼き込み**（`bake_stage`。job に `bake` があるとき）→ **書き出し**（glb）→ gltf-transform（KTX2・meshopt）→ **ライトマップを glb へ**
（`scripts/assets/pipeline.mjs`）。

- **焼く物**（`bakeable_material`・`bake_targets`）: 名前のある見た目の物（`_col` でも、詳細度 1 以上でもない）のメッシュで、焼ける材質の面を
  持つもの。焼ける材質 = 透過でない・ガラスの印がない（乳白の灯りの器も印のガラス）・材質の `bake` が False でない（`make_workshop.py` が火・熾火・
  ガラスの中の泡に付ける）。焼いた物の焼かなかった材質には、パイプラインが `bake: false` を書く（材質の extras。ゲームはそれを読む: 規則を
  2 か所で導かない）。焼かない材質の面は展開せず UV を (0, 0) に潰す（`common/bake.py` の `exclude_materials`）。工房では 23 物（ガラスだけの
  作品 5 物と当たり判定は焼かない）。詳細度 1 以上は同じ所に重なる粗い形なので今は焼かない（まだない。焼くなら段ごとに焼く）。
- **焼く間だけ場面を変える**（`BakeScene`、終わったら戻す。.blend は保存しない）:
  - ガラス（透過の材質）とガラスの中の泡（焼かない光らない材質）は**すべての光線に透明**（Transparent BSDF）、吸収も外す。ゲームのガラスは影を
    落とさず光を通す。はじめは影の光線だけ透明にしていて、泡（不透明な金属の球）とガラスで屈折した拡散の光線のせいで、泡入りの瓶やガラス棒の下が
    暗いしみになった（レビュー1巡目 P1。Blender の単体 `test_glass_and_the_air_in_it_cast_no_shadow_in_the_bake`: 前の作りでは泡の下が 0.28 倍）
  - 焼く材質の金属を 0 に（拡散の焼き込みは金属では 0）
  - 当たり判定と詳細度 1 以上を隠す（工房の `_col` は make_workshop.py が描かない物にしてあるが、手で作る .blend でも同じになるように）
  - 光の模様（コースティクス）を切る（S-32 で別に描く。初めはガラスの器の下に雲のような粒が出た）。間接光の強い標本を 4 で切る。透明の面を
    抜ける数の上限を 64 に（棚の作品の二重の壁）
  - 画像のノードの UV: 焼く間は Lightmap が描画用の UV になるので、UV のノードのない画像のノードに元の UV をつなぐ（common の修正）。
    工房のアトラスは `make_workshop.py` で 1つ目の UV につないである
- **光と空**（`make_workshop.py` の `bake_lights`・`dawn_world`。書き出さない）: ゲームの実時間の光と同じ値
  （`room-art.ts` の `WORKSHOP_LIGHTS` に集めた）を Blender の単位で置く。半影の形は three と同じ曲線（単体が 200 点で比べる。差 0.001 未満）。
  - 日: 平行光 0xffbd86・2.5 → 太陽 2.5 W/m²（three の平行光の強さは照度）。見かけの角 1.5 度
  - 空: ゲームの環境画像と同じ空（天頂の紺・地平の青灰・夜明けの方の暖色、街の暗い帯、夜明けの光の球）に半球光（0x7890c0 / 0x181c28・0.8 を
    放射輝度 = 照度 / π で上下の半球に）を足した正距円筒の画像（512×256、EXR で .blend に詰める）
  - 天窓の青: スポット (0.52, 0.66, 1.0)・26 cd・減衰 1.4 → Blender は 1/d² だけなので、玉に届く所で同じ明るさ（4π × 26 × d^0.6 = 735 W）
  - 炉の火: スポット 0xff6a2a・7.5 cd → 94 W（4π × cd）、同じ位置・向き・広がり（160 度）。影は物理どおり（ドームの開口が光を切る）。
    three の 7m の距離の窓（5m で 0.55 倍）は Blender にないので、焼いた火は遠くで少し明るい
  - スポットの半影: three は角 × (1 − penumbra) の内が全強度、Cycles は余弦の幅 × blend で smoothstep するので、全強度の縁を揃えて
    blend = (cos(A(1−p)) − cos A) / (1 − cos A)（炉 0.6 → 0.82、天窓 0.75 → 0.94。Blender 5.2.2 の Cycles の kernel `spot.h` で式を確かめた。
    レビュー1巡目 P2 まで penumbra をそのまま渡し、全強度の円が倍ほど広かった）
  - 炉の口の奥の火・覗き窓の乳白・徐冷炉の熾火は発光の面のまま光る（焼かない面だが場面の光）。焼いた炉の光はスポットと口の奥の発光の面の
    両方で、`WORKSHOP_LIGHTS` と照らし合わせるのはスポットだけ
  - 焼いた光と空は glb の scene の extras（`bake.lights`、`bake.world`）に残り、`src/game/assets/workshop-bake.test.ts` が `WORKSHOP_LIGHTS` と
    照らし合わせる（片方だけ変えると落ちる）
- **ライトマップ**: エリアごとに 1 枚（`A0_lightmap`）。`common/bake.py` が物を 1 枚に詰め直して（smart project ＋ pack）焼き、高い方の百分位で割った
  8bit の sRGB PNG と倍率 `lightmap_scale` を書く。物の extras に `lightmap`（画像の名前）と `lightmap_scale`。
  - **glb の中に KTX2**（決定どおり）: gltf-transform はどの材質も使わないテクスチャを書き出しで落とすので、圧縮の後に `ktx create`（ETC1S、
    sRGB、ミップマップ、`--qlevel 255`）で KTX2 にして、glb の JSON とバイナリに直接足す（`lib.mjs` の `addTexture`。KHR_texture_basisu、
    端は CLAMP）。`ktx` がなければ PNG のまま入れる。`bake.codec: "uastc"` で UASTC（比べるため。判断待ち 2）
  - ETC1S の 4×4 のブロックが近い滑らかな面（炉の殻、天板）に色の斑として出る。ETC1S の設定を変えても良くならない（焼いた PNG に対する
    PSNR: qlevel 255 で 40.2 dB、RDO なしで 40.2、clevel 5 で 40.7。UASTC は 55.7）。判断待ち 2
- **焼かない切り替え**: `BAKE=0 pnpm assets`（か `-- --no-bake`）。2つ目の UV は物ごとに作るだけで、ゲームは今までどおり実時間で照らす
  （確かめた: S-24 の e2e が緑、目覚めの絵は焼く前と同じ）。
- **Cycles の設定と所要時間**（Apple M5 Pro、Blender 5.2.2、Metal。設定は `blender/pipeline.json`）:

  | 大きさ | サンプル | 焼く時間 | 見た目 |
  |---|---|---|---|
  | 1024px | 32 | 13 s | 床が 1024 の 2% にしかならなかった（島の間の余白の測り方。下） |
  | 2048px | 64 | 18 s | 床に粒（暗い所のざらつき） |
  | **2048px** | **512** | **43〜56 s**（Blender 全体 48〜61 s、`pnpm assets -- --job workshop` 全体 約 1 分） | 粒は ETC1S の後には見えない。**これにした** |

  - 2048px（GPU 上 2.8MB）で、床（直径 9.3m）は 1 texel ≒ 7mm、作業台の天板 ≒ 6mm、ほかは ≒ 15mm。物ごとの細かさ（`density`）: 床 2、
    作業台 2.5（最初の絵の天窓の光の輪）、炉・マーバー台・徐冷炉 1.5。細い管の多い物（ドームの枠）は 1 のまま（0.3 にすると面が 1 texel を切って
    黒い斑になった）
  - 正規化の百分位は **99.9**（`common/bake.py` の既定 99.99 では倍率 34 になり、炉の口の真下の床と真鍮の数千 texel だけで 8bit が埋まって、
    部屋の暗い所の段が粗くなった。99.9 で倍率 2.7〜3.2、切れるのは炉の真下の 0.1%: 格子の真鍮の下でほとんど見えない）。倍率は最大の成分で
    決め、切るのは成分ごとなので、切れた所の橙は黄白へ寄る（最後の焼き込みで max/scale 47.5）。ログの「切れています」の WARNING は百分位どおりなら出さず、
    行に「(by its percentile)」と書く
  - 焼いていない画素（島の間）は PNG に書く前に近くの島の色で埋める（common の `fill`。レビュー1巡目 P2: 4px の余白の外は黒のままで、ミップの
    粗い段で細い島に黒が混ざる）
  - 2つ目の UV は meshopt で 14 bit に（既定の 12 bit は 2048px の半 texel 刻み）
  - 焼き込みは決定的（同じ設定で焼き直すと倍率 2.73257 も PNG も同じ）。glb の scene の extras には光を決める値だけを書く（かかった秒と計算機は
    ログと報告だけ）。ただし ETC1S の符号化は数百バイト揺れるので、glb のバイトは焼き直すたびに少し変わる
  - 島の間の余白は 4px（`margin`）、`pack_islands` の FRACTION で（common の修正。既定の SCALED では小さな島が千個ある工房で余白が大きくなりすぎ、
    床が 1024px の 2% にしかならなかった）

### 床とドームの真鍮（受け入れ条件2の「床やドームの殻」）

**Blender の工房のファイルへ移した**（同じライトマップに含める方法 = コードの形に UV を合わせる方は、管の UV を合わせられないので採らなかった）。
- `A0_flr_floor01`（`make_workshop.py` の `floor`）: room-art.ts の床の円盤の上の面（下と縁は台座の岩に埋まって見えないので作らない。ライトマップの
  場所を取る）。材質 `A0_floor` の extras `procedural: frosted_floor`・`tile_size: 0.9`・`frost_color: #a7b1bc` をゲームが読んで、今までと同じ
  コードの床（`createFrostedFloorMaterial`: タイルのむら、画素の大きさに合わせて消える真鍮の目地）に作り直す（`src/game/assets/procedural.ts`）。
  焼き込みでの色はタイルの平均の色
- `A0_bld_frame01`（`dome_frame`）: room-art.ts と同じ並びの真鍮の管（扉を避けた 12 本の経線、扉の両側の経線と上の緯線、天窓・裾・中ほどの輪）。
  色はアトラスの真鍮の中ほど（= room-art の BRASS_COLOR）
- ドームのガラスの殻と床の下の岩はコードのまま（ガラスは焼かない。岩は外）。room-art.ts から円盤と枠を外した
- `WORKSHOP_OBJECTS`（layout.ts）に `floor`・`frame` を足した。描画呼び出しは同じ（コードの 2 つが glb の 2 つになった）。
  **範囲**: spine の S-26 の paths にある prologue の物は room-art.ts だけだが、親の指示（「工房の物の名前や部品が変わる分だけ layout.ts」）に
  従って足した。glb の物は WORKSHOP_OBJECTS にすべてなければならない（`workshop-asset.test.ts` の照合、room.ts の `missing`）

### ゲームの側（受け入れ条件3）

- `src/core/assets/lightmap.ts`（共通。CHANGELOG に 0.11.0 の案）: extras の読み取り、glb の中の光の画像の読み込み（名前で探し、2つ目の UV・sRGB）、
  焼いた物の材質を `BakedStandardNodeMaterial`（lightMap、強さ π × lightmap_scale: 焼いた値は白い拡散面の放射輝度、three の lightMap は放射照度）に。
  `createGltfLoader().load(url, { lightmaps: true })`。焼いた材質は材質の extras の `bake: false`（パイプラインが書く）で決まる。physical の材質は
  焼いた版を作れないので実時間のまま残して問題に挙げる（`lightmap-material`。工房にはない）
- **二重にかからない**（`BakedLightingModel`）: 焼いた材質は拡散の光をライトマップからだけ受ける。実時間の日・天窓・炉の灯りは拡散を足さず鏡面
  （ハイライト）だけ、半球光と環境画像の拡散も足さない（焼いた空が持っている）。環境画像の映り込みは、金属でない面では焼いた光が開けた空より暗い所で
  暗くする（作業台の下の棚が空を映さない）。金属は拡散がなく焼いた光は見た目を変えない（映り込みを暗くすると細い管が黒い斑になった: 見た目の調整 1巡目）。
  確かめ方: 単体（three の PhysicalLightingModel の上で、実時間の光は鏡面にだけ・拡散はライトマップだけ・環境は映り込みにだけ足されることを、
  足された節点が何から作られているかで見る。three を上げたときの見張り）。e2e: 実時間の光を全部消しても目覚めの視点の下半分の明るさの 87% が残る
  （焼く前は 61%）、光と環境の両方を消しても焼いた天板（つや消し）の明るさの 99% が残る（環境の拡散が二重なら、その分が消える。焼く前は光だけで
  34% に落ちた）。この天板の検査は粗い見張り: 環境の拡散を二重にした作り（`indirect` の捨て場を外した）では 95.2% 残り、しきい値は
  その間の 97.5%（守りの本体は単体）。扉から見た開けた床の明るさが焼く前（spec に定数で持つ）の 0.91〜0.95 倍（強さの π の誤りなら sRGB と AgX を
  通って 1.5〜1.7 倍ずれる）
- **動く物は実時間のまま**: 手の玉・作業台と台座の玉・雫・置いた玉の受け・橋・道・門など、glb の焼いた物でない物の材質は今までどおり（e2e で
  lightMap がないことを確かめた）。実時間の光（日・半球光・天窓・炉）は room-art.ts にそのまま残る
- **実時間の影の扱い**: 日の影の地図（1 回だけ描く、S-01 から）と天窓の影（1 回だけ）はそのまま。焼いた物では鏡面のハイライトにだけ効き、拡散の影は
  焼いた影が持つ。外の道・門・台座（焼いていない）には今までどおり効く。床（kind `flr`）は影を落とさない（コードの円盤のときと同じ。床の上にある物を
  影にすることはない）。動く物（手の玉・置いた玉・雫）は今までどおり影を落とさない（S-06 から:
  毎フレームの影の地図は WebGL2 のタイムスタンプの溜まりを溢れさせる）。焼いた床に動く物の影を落とすなら、焼いた光に掛ける影の印（shadow mask）が
  要る（判断待ち 4）
- 炉の灯りの揺らぎ（±8%）は、焼いた床・壁の拡散では止まった（焼いた火は平均の強さ）。揺らぐのは鏡面のハイライトと、焼いていない物（玉）だけ（判断待ち 3）

## 判断待ち

1. **見た目の最終判断**（`compare.png`）: 炉の無地の面の陰影、工房の平たさ（家具の影・真鍮の影・下の棚の陰）。決まるまでは焼いた版
2. **ライトマップの圧縮: ETC1S（決定）か UASTC か**（`compare-codec.png`、扉から振り返るの左下の炉の殻）。ETC1S は近い滑らかな面に 4×4 の色の斑が
   出る（PSNR 40.2 dB）。UASTC は出ない（55.7 dB）が、glb 1.36 → 3.26MB、GPU 2.9 → 5.7MB（この機械。どちらも予算の内）。案: ライトマップだけ
   UASTC（`blender/pipeline.json` の `bake.codec: "uastc"` の 1 行）、ETC1S のまま 4096px にしてブロックを小さくする（GPU 約 11MB、焼く時間約 4 倍）。
   **推奨: ライトマップだけ UASTC**（近くで見る滑らかな面が多い）。決まるまでは ETC1S
3. **炉の火の揺らぎと広さ**: 焼いた拡散では揺らぎ（±8%）が止まった。焼いた火は口から出る分だけなので、炉の前の床の暖かい光が前（影のないスポット）
   より小さい。案: (a) このまま、(b) 炉の灯りは焼かず、焼いた面にも炉の拡散だけ実時間で足す（光ごとの印）、(c) 炉の光だけ別のライトマップに焼き、
   揺らぎでその強さを変える（GPU +2.8MB）。**推奨: (c)**（揺らぎは火らしさの大きな部分。広さは炉の前の床だけで足りる）。決まるまでは (a)
4. **動く物の影**（設計書 技術設計 > 品質プリセット: 動く物の影 低 なし（焼き込みのみ）・中 1024px・高 2048px）: 今も動く物は影を落とさない
   （後退ではない）。焼いた面は実時間の影を鏡面にしか使わないので、焼いた床に手の玉や置いた玉の影を出す道がまだない。案: 焼いた光に掛ける影の印
   （shadow mask: 動く物だけの影の地図で焼いた光を暗くする）、玉の下の丸い影（安い）。**推奨: 玉の下の丸い影**（中・高の品質で。動く物は玉と雫
   だけ）。決まるまではなし（今までどおり）
5. **目覚めの絵の天窓の光の輪**: 前より縁が柔らかく目立たない（跳ね返りで天板が明るい）。案: 焼く天窓のスポットを強める、絞る。**推奨: 1 の判断と
   一緒に**（実時間の光と同じ値で焼く今の約束を崩すので、`WORKSHOP_LIGHTS` ごと変える）。決まるまでは今のまま
6. **炉の殻の継ぎ目と筋**（残件の 1 行目）。**推奨: 炉の殻に手で作った Lightmap UV**（回転の形なので円筒の展開で継ぎ目を裏へ回せる）。
   決まるまでは今のまま
7. **表裏の層の焼き込み（エリア1 から）**: 今は同じ場面で焼くので、実体化の前は見えない裏の層の物の影が表の床に焼き込まれる（工房には裏の物がない）。
