## 設計の決め（仮。設計書に数のないもの）

| 項目 | 決め | 場所 |
|---|---|---|
| 時間の止まり方 | 開く: 曇りの広がり f = glassEase(t / 0.4)、ゲームの時間の速さ = 1 − f（0.4 秒で 1 → 0）。閉じる・タイトルへ: 同じ曲線を 0.3 秒で逆に（f が戻り、速さ 1 − f が 0 → 1）。途中で閉じる・開き直すと、そのときの f から続ける（跳ばない） | `src/ui/pause/pause-logic.ts` PauseTimeline |
| 時間の速さの効く所 | 部屋（`room.ts`）が受け取る dt に速さを掛け、部屋の時計（`art.animate` などの t）もその dt で進める。体・玉（覗く・置く）・光の掃き（序章の橋、近道）・灯りや雲の動き・自動操縦がすべて同じ時計で止まる。main の t とはずれる（位相にしか使っていない） | `room.ts` の殻の `update` |
| 入力を預かる | 開いている間（opening・open）は部屋の入力を止め（`suspended`）、マウスの固定を外し、操作表示を消す。`playing` は true のまま（ホームの殻がカメラを動かさない）。閉じ始めたら返す。パッドの Start で閉じたフレームは、部屋の入力がその Start を新しい押下と見ないよう、預けを外すのを次のフレームにする | `room.ts` setHeld、`pause-host.ts` |
| 文字 | 項目は1行ずつ曇りガラスの札（文字の長さに合わせて伸びる）に、左から右へ光の筆跡（指先の光）とともに 0.3 秒で書く。行は 0.35 ずつずらして重ねる。閉じるときは逆に消す（晴れる前半で消える）。確認のページも同じく書き直す。本文は明朝体、項目 max(22px, 2.5vh)、小さな文字は max(18px, 1.85vh) | `pause-screen.ts`、`styles.ts` .vd-pause |
| 曇り | 画面いっぱいの曇り（白 17%（中心）〜10%（外）、背後をぼかして暗く: blur 2→12px（1080p）、brightness 0.8）を、中心のやや下から広げる。縁のやわらかさは半対角の 0.5、3 つの円を少しずらして重ね、息のような不揃いな縁にする。広がり切ったらマスクを外す | 同上 |
| 項目と操作 | つづける / タイトルへ（ヒント・地図の玉・設定は後のスライス）。上下（WASD も）・Enter / Space・Esc / Backspace、パッドの十字・A・B・Start（Start はどのページからでも閉じる）。確認は「タイトルへ戻りますか」と「はい / いいえ」で、いいえを選んだ状態で出る。Esc / B / いいえで項目へ戻り「タイトルへ」にフォーカス。ホバーで膨らんで鳴りフォーカスが移る（マウスが動いたときだけ。止まったマウスの下にページが出ても、キーやパッドのフォーカスを取らない）。選ぶと沈む。フォーカス中の札は内側に光が灯る。クリックで出したページ（確認、確認から戻った項目）は、ポインタが動き、ページが書き終わるまでクリックを受けない（「タイトルへ」のダブルクリックの2回目が、その下にまだ見えない「はい」に当たらないように） | `pause-logic.ts` stepMenu・pickItem・keyCommand・padCommands、`pause-screen.ts` |
| マウスの固定 | つづけるをクリック・Enter / Space で選んだときは、その押下の中で固定を求め直す（Esc はユーザーの操作として数えられないので求めない）。ポーズの下に「つづけたあと、画面をクリックすると視点を動かせます」を曇りガラスの小さな文字で出す。再開後に固定が戻っていなければ、部屋の操作の案内（S-06）も 8 秒出る | `pause-host.ts`、`room.ts` relock |
| Esc の二重 | 固定を外す Esc の後に同じ Esc がキーとして届くブラウザがある（S-03 の ESC_ECHO_MS）。開いてから 0.3 秒の Esc は閉じる操作に数えない | `pause-logic.ts` ESC_ECHO_MS |
| 描画を止める | 時間の速さが 0 になったら、止まった絵を 1 枚描いた後は世界を描かない（ホームの殻の render が `holdsFrame` を見る）。キャンバスの大きさ（描画の倍率）が変わったら 1 枚だけ描き直す。曇りと文字は DOM（backdrop-filter）で、止まったキャンバスの上にある | `dive-host.ts`、`pause-host.ts` |
| タイトルへ | 「はい」で、ホームの殻が潜る遷移を逆に再生してホームへ（`flow.rewindFromGame`、S-04 の検証用シーンの Esc と同じ道）。曇りは閉じるときと同じく 0.3 秒で晴れ、その下で遷移が始まる（2.0 秒、黒い画面なし）。潜る道の終わりを遊んでいた所の目（位置・向き・霞）へ寄せる（`towardEye`。遷移の値でなく時間で動かす）。工房の中なら、天窓を抜ける所（u 0.62）から先を、目が着地の姿勢からずれた分だけずらし、視線は u 0.3 から目が着地の姿勢から振り向いた分（yaw・pitch の差）だけ回す（初回は差が 0 なので、潜る遷移は変わらない）。工房の外なら、工房の上（u 0.15）から潜る道を離れ、町の上を弧を描いて目の真上へ先に渡り（時間の 0.92 まで）、降りる。視線は潜る道の視線（工房を見下ろす）から目の視線へ回す。弧の高さは道のりの 0.2 倍、6〜50m。霞は曲げた後のカメラの位置から。ドームも町の物も突き抜けない。戻りは遊んでいた所から引き上がり、もう一度「はじめる」で潜るとそこに立つ（遊んだ状態はそのまま: 判断待ち 4） | `room.ts` の `towardEye`・殻の `pose`・`eyePose`、`dive-host.ts` |
| 音 | ポーズの音は合成の仮置き（`src/audio/pause.ts`、録音に差し替えられる SoundSource）。開く: 息（帯域ノイズが 0.4 秒でふくらむ）＋ D5、書き始めに A5。閉じる: A5 → D5（開くときの逆）＋晴れる息。項目: 各項目の音階の音（D5・E5、確認の答えは F#5・A5）、選ぶと 1 オクターブ下（沈む）。タイトルへ: A5 F#5 D5 A4 と下がる。ページのエンジン（AudioGate）の効果音の系統で鳴らす。合成が済む前はゲートの仮の音で応える | `src/audio/pause.ts`、`pause-host.ts` |
| ゲームの音を絞る | 曇りに合わせて環境音の系統をプレイヤーの音量の 0.4 倍まで下げる（約 −16dB、小さく残す）。効果音の系統はポーズ自身の音が通るので下げない。足音（環境音の系統）と出来事は、時間が止まるので新しく鳴らない。ただし、開いたときにすでに鳴っている出来事の音（光の掃き約 4 秒、門約 4.2 秒、近道約 8.4 秒、ささやき 1.9 秒）は最後まで鳴る（判断待ち 2）。タイトルへ戻るとき、ゲームの環境音はポーズの絞り（0.4 倍）のまま、逆再生の 2 秒でフェードアウトし（ホームには部屋の音がない、初めて見たときと同じ: 判断待ち 5）、もう一度遊び始めたら 0.3 秒で戻す。設定（S-43）がポーズ中・タイトルへ戻った後に音量を変えるときは `PauseMix.setUserVolume` を通す | `src/audio/pause.ts` PAUSE_DUCK・AWAY_DUCK・PauseMix |

## 範囲外に触れた所（paths の中だが、書かれた用途より広いもの）

- `src/game/prologue/room.ts`: spine は「ポーズの配線と時間の速さだけ」。配線（求める・預ける・固定し直す）と時間の速さ（殻の update）の
  ほかに、「タイトルへ」のための潜る道の寄せ（`towardEye`、殻の `pose`、BuiltRoom の `eyePose`、約 50 行）を足した。戻る・もう一度潜る
  ときに、潜る道の終わりを遊んでいた所の目に合わせないと、遊んでいた所から着地の姿勢へ跳ぶ（黒い画面ではないが切れ目になる）。霞（霧の
  距離）は部屋の中でしか決められないので、ホームの殻ではなく部屋に置いた。整形で既存の行は動かしていない。既存の行を書き換えたのは 7 か所:
  layout の import（2 名を足す）、殻の `pose` の霞の 2 行、`prepare` の `buildRoom` の呼び出し、殻の `update`、`handle` の最後の `}`、
  `updatePrompt` の最初の `if`、`setPlaying` の `input.suspended`。ほかは追加。S-41 と試しにマージすると 5 か所で重なる（レビュー 1 巡目:
  PrologueRoom の型、Shell、バスの宣言、`prepare`、`dispose`）が、どれも両方を残せば解ける。統合で S-41 の `gates` を `shell` に足すのを
  忘れないこと。判断待ち 3。
- `src/ui/home/dive-host.ts`: spine は「ホームへ戻る口だけ」。戻る口（`flow.rewindFromGame` を「はい」に渡す）のほかに、ポーズの持ち主を
  ここに置いた（作る・毎フレームの update・描画を止める判断・大きさ・片付け、約 25 行）。シーン（prologue-proto）は先頭のコメントしか
  触れないので、部屋とページの音（AudioGate）とホームの流れ（ScreenFlow）を両方持つ所がここしかない。ポーズは読み込み・ホームと同じく
  画面の一つとして殻が持つ。世界がポーズの口を持つかどうかは `pausableOf(world)`（形で判定）で見る。DiveWorld（`src/game/dive-world.ts`）
  に口を足すのは範囲外なので提案 1。

## 実装の途中で直したこと（試行 1 の中）

1. 再開後に W で歩く確かめが 0.04m しか動かない: 着地から前へ歩くと作業台に当たる。テストを S（後ろへ）にした（実装の問題ではない）。

   ページが出た瞬間の pointerenter がフォーカスを取っていた。ホバーは、ポインタが実際に動いたとき（座標が変わった pointermove）だけに
   した。

   預けを外した直後に部屋の入力が読む）。預けの切り替えを、そのフレームのボタンを読む前の状態で行うようにした（部屋はその Start を
   押されたままと見る）。
4. 開いた後の環境音の音量が 0.4006: 毎フレームの音量の送信で小さな差を省いていたため、最後の一歩が送られなかった。広がり切った値は

## S-43（設定パネル）への引き継ぎ

- 項目: `src/ui/pause/pause-logic.ts` の `PAUSE_ITEMS` に `settings` を設計書の順（つづける / ヒント / 地図の玉 / 設定 / タイトルへ）で
  足し、`choose` で扱う。設定のパネルが開いている間は、ポーズのキー（`PauseHost.onKey`）とパッド（`pollPad`）がパネルに譲ること。
  戻る（Esc / B）はパネル → ポーズの項目 → ゲームの順。
- 景色: ポーズ中は世界を描かない。「パネル越しに見える景色で結果を確かめられる」ためには、絵の変わる設定（画質・視野角・明るさ）を
  変えたら PauseHost に描き直しを求める口（今は `resize` だけが `needsFrame` を立てる）を足す。曇り（`.vd-pause__breath`）は設定を
  開くときに薄くするかどうかも決める。
- 音量: ポーズ中とタイトルへ戻った後のホームでは、環境音を `PauseMix` が下げている。設定の音量は `PauseMix.setUserVolume`（と
  `userVolume`）を通す。通さずに `engine.setVolume` すると、閉じたときに古い値で上書きされる（提案 3 で core に絞りの段ができれば不要）。
- 文字: 札の作り（`.vd-pause__tag`、文字に合わせて伸びる）と指でなぞった文字（`writtenLine`、`lineWriting`）は、パネルの見出しにも使える。
