## 赤の証跡

直す前のビルド（`room.ts` の `warm()` を元の `pipeline.render(frame)` に戻して `pnpm build`）で `pnpm exec playwright test tests/e2e/S-38-warm-glass.spec.ts`:
両経路とも `Error: A0_ware_anneal01 compiled while loading`（読み込み中に作られた物の一覧にない）で落ちた。そのときの記録
（`artifacts/S-38/pipelines-<経路>.json`）: `game:look-back` で 5 つ、すべてガラス（`A0_anl_annealer01` 曇り、`A0_ware_anneal01` 透明、
`A0_tub_water01` 曇り、`A0_ware_cart01` 透明、`A0_ware_marver01` 気泡）。ほかに `home-game`（潜る遷移）で 3 つ（棚の `A0_ware_frost01`・
`A0_ware_bubble01`・`A0_ware_clear01`）。段 `look-back` の最長は WebGPU 45.8 ms、WebGL2 56.0 ms。

最初の赤の実行では、WebGL2 が別の行（「読み込み中にガラスが 10 個より多く作られる」という記録の確かめ）で先に落ちた。直す前は
ちょうど 10 個だったため。確かめの目的（記録が働いている）には「1 つ以上」で足りるので直し、上の実行で両経路とも同じ理由で落ちることを確かめた。

## 原因（調べたこと）

- **何が作られていたか**（`?debug=1` の renderer の backend の `createRenderPipeline` と `createProgram` を包んで、作られた時の段と一緒に
  数えた。スクリプトは一時的なもので、コミットしていない）: 直す前、着地の後に作られるのは段 `look-bench`（着地の最初）の仕上げの
  全画面パス 5 つ（RTT・ブルーム。下の「残件 1」）と、段 `look-back` の工房のガラス 5 つだけ。S-34 の調べでは 8 つ（棚の 3 つを含む）
  だったが、今は棚の 3 つは潜る遷移の間（`home-game`）に作られている。
- **なぜ読み込みで作られないか**: three は描く前に視錐台で間引く。読み込みの温め（dive-host の `compileAsync` と、部屋の `warm()` の
  1 回の描画）は、どちらもミニチュアの姿勢（工房の上の後ろ (12, 32, 40) から谷の先を見下ろす。下向き約 15 度、縦の視野 44 度）から
  描くので、工房のドームの +Z 側（台の後ろ、徐冷炉、カート、マーバー）は視界の下に外れる。潜る遷移も着地も -Z を向いているので、
  向こう岸で振り返るまで一度も視界に入らない。
- **試したこと（一時的な切り替え。コミットしていない）**:
  1. **部屋の `warm()` で全部の物の間引きを外す**: `look-back` で作られるものは 0 になり、`look-back` の最長も 18.6〜18.9 ms に戻った。
     ただしその 1 フレームで影を落とす物すべてが影の地図に、裏の層すべてが覗く像にも描かれ、読み込み中のフレームの描画呼び出しが
     **345 回**（予算 300。S-06 の autoplay の e2e は読み込み中のフレームにも予算をかける）。
  2. **dive-host の `compileAsync`（玉の中の像の描画先）で全部の間引きを外す**: シェーダ（プログラム）は読み込みで作られるようになったが、
     `look-back` では 5 つのパイプラインがやはり作られ、最長は 41〜49 ms のまま。同じ形式の描画先（rgba16float / depth24plus / 1 サンプル）
     でも、`compileAsync` が作ったパイプラインを実際の描画は使わなかった（潜る遷移の間の玉の中の像の描画でも作り直した。理由は
     未確定。three r186 の `compileAsync` と描画のキャッシュの鍵のどこかが違う）。S-34 の「作業台の前から後ろ向きに描く」試しが
     効かなかったのも、同じ種類の食い違いだったとみる。
  3. **採用: 部屋の `warm()` で、背景を読む材質（透過のガラス）の物だけ間引きを外す**: ゲームの描画（scene pass、その透過の背景、
     層のマスク）そのもので 1 回描くので、同じパイプラインになる。ガラスは影を落とさず（`castShadow` なし）、覗く像にも入らない
     （層のマスク）ので、増える描画はその scene pass のガラスだけ（読み込みのフレームの描画呼び出し 221 → 229 回。レビュー 2 巡目の後は
     ガラスの下の覗く像の代わりの物も入れて 237 回）。
