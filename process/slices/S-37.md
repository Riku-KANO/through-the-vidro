## 作ったもの

### Blender: 光を分けて焼く（受け入れ条件1）

- `blender/scripts/common/bake.py`（common 0.2.4 の案）: `BakePass(layer, scene, percentile)` と `bake_lightmaps(..., passes=[...])`。同じ物の
  2つ目の UV を 1 回だけ作り、枚ごとに `scene()` の文脈に入って焼き、枚ごとの百分位で正規化して別の PNG（`<name>_<層>.png`）に書く。
  物のカスタムプロパティ `lightmap_layers` = {層: {lightmap, lightmap_scale}}。2 枚目からの島の間の塗りは 1 枚目の焼いた画素を島とみなす
  （空のない枚では島の中の届かない画素が多い）。1 枚目はいつものライトマップでなければ ValueError。戻り値に `layer` と枚ごとの `seconds`
- `blender/scripts/pipeline.py`: `bake_layers`（光の物と光る材質の `bake_layer`、材質の `bake_clear_for` から層を読む。.blend が自分で言う）と
  `LightPass`（文脈）。いつものライトマップ = 層の光を隠し、層の光る材質の発光を 0 に。層のライトマップ = 空なし（`scene.world = None`）、
  その層の光と光る材質だけ、`bake_clear_for` にその層がある材質は影の光線に透明（Light Path の Is Shadow Ray で Transparent と混ぜる）。
  終わったら元に戻す。焼き込みの記録（glb の scene の extras `bake`）に `layers`（光・光る材質・通す材質）と枚ごとの `layer`
- `blender/scripts/make_workshop.py`: 炉の火のスポット `bake_fire`、材質 `A0_fire`（口の奥の火）・`A0_ember`（徐冷炉と覗き窓の熾火）・
  `glass_milky`（覗き窓の乳白の輪。工房の乳白の印はこれだけ）が `fire` の層。`A0_kiln`（炉の体）と `A0_fire`（火の洞）は炉の光を通す
- `scripts/assets` は変えていない（画像の一覧の各枚を glb に入れる作りのまま、2 枚目も同じ道で KTX2〈UASTC〉になって入る）

### 炉の体と火の洞を炉の光に透明にした判断（受け入れ条件2）

分けて焼くだけ（見た目の調整 1 巡目）では、炉の前の床の暖かさは S-26 とほぼ同じだった（炉の前の暖色の量 8.9、S-31 は 15.1）。焼く炉のスポットは
火の洞（`A0_fire` の管）の中に立ち、洞の壁と炉の体（ドーム）が光を口の開口の分だけに絞っていた。S-31 の実時間のスポットは影なしで体と洞を抜け、
炉の足元から口の向きの床を広く暖めていた。2 巡目で、炉の光の枚だけ炉の体と洞を影の光線に透明にした（`bake_clear_for`）。日と空の影は今までどおり
（いつものライトマップでは不透明）。理由づけは「S-31 の影のない実時間の灯りに合わせる近似」。炉の体は厚い曇りガラスを不透明に描いたもの（S-30）で、
光を通すのは「温度のある透明」にも沿うが、体そのものは炉の光で照らされない（外の面は光の裏）ので、物理の写しではない（レビュー1巡目の指摘）。
判断待ち 1。

### ゲーム: ライトマップを重ねて揺らす（受け入れ条件1）

- `src/core/assets/lightmap.ts`（core 0.13.0 の案、CHANGELOG）: extras の `lightmap_layers` を読む（`lightmapLayersOf`）。
  `BakedStandardNodeMaterial.lightMapLayers`（層、画像、強さ π × scale、gain）。焼いた光 = ライトマップ ＋ Σ 層の画像 × 強さ × gain を
  `setupLightMap` が `IrradianceNode` にし、同じ節点を `BakedLightingModel(baked)` が「焼いた光」として読む（場面のほかの放射照度〈半球光〉と
  見分ける）。節点は node builder ごとに 1 つ（呼ばれる順によらない）。層は `customProgramCacheKey` に入る（three r186 は鍵が同じ材質で組んだ
  シェーダを共有し、層の画像・強さ・gain はシェーダに固定されるため）。`copy`/`clone` で層を写す（`LayerField` は材質を clone する）。
  `applyLightmaps(root, maps, { gain })`、`loadLightmaps` は層の画像も読む
- `src/core/assets/loader.ts`: `load(url, { lightmaps: { gain } })`
- `src/game/assets/baked-light.ts`: 層ごとの共有の uniform `bakedLightGain(layer)`（1 = 焼いたまま）、`FIRE_LIGHT_LAYER = 'fire'`。`area.ts` が
  ローダーに渡す
- `src/game/prologue/room-art.ts`（配線だけ）: `animate` で火の揺らぎ `breath` を 1 回計算し、火の灯りの強さ（`FIRE_INTENSITY × breath`）と
  焼いた炉の光の強さ（`bakedLightGain('fire').value = breath`）の両方に入れる。毎フレームの仕事は代入 1 つ
- 描画呼び出しは増えない（同じ材質の中で画像を 1 枚多く読む）
