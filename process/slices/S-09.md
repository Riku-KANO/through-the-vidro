## 音の設計

### 音階と大きさ→音程（`src/audio/tuning.ts` が規則、`src/core/audio/scale.ts` が計算）

- 平均律、A4 = 440 Hz。`VIDRO_SCALE` = 根音 D、音程 [0, 2, 4, 7, 9]（D E F# A B）。
- `glassPitch(size)`: 生の音程 = 81（A5）− 12 × log2(size / 0.1 m)。振動する殻を相似に大きくすると f ∝ 1/大きさ なので、
  大きさが倍で1オクターブ下。D2（38, 73 Hz）〜 D7（98, 2349 Hz）に収め、最寄りの音階の音へ吸着（同点は下へ。単調性が崩れない）。
- 実験室のガラス（直径）: 0.40 m → A3 220 Hz、0.26 → E4 330、0.18 → B4 494、0.12 → F#5 740、0.08 → D6 1175。

### ガラスの音（`src/core/audio/glass.ts`、モード合成）

- 倍音比: Rayleigh の薄い殻の曲げモード f_n ∝ n(n²−1)/√(n²+1)、n = 2..5 → **1 : 2.83 : 5.42 : 8.77**（各 ±0.6% ずらす）。
- 基音は対で鳴らす: 0.05〜0.25% 上に 0.35 倍の音を重ね、ゆっくりうなる（実際のガラスの縮退したモードの分裂）。
- 強さ:

  | | 全体の大きさ（ピーク） | 倍音の明るさ b（モード k の比 = b^k） | 立ち上がり | 打撃のノイズ | 鳴りの長さ |
  |---|---|---|---|---|---|
  | 触れる | 0.20 | 0.12 | 12 ms | なし | ×0.6（指で減衰） |
  | 叩く | 0.45 | 0.35 | 2 ms | 0.07, 6 ms | ×1 |
  | 玉が当たる | 0.75 | 0.60 | 0.5 ms | 0.12, 4 ms | ×1 |

- 減衰: 基音の T60 = 1.6 s × (大きさ / 0.1 m)^0.35（0.5〜6 s）。高いモードは T60 / 比^0.7。線形の立ち上がり → 指数減衰（τ = T60 / ln1000）。
- 揺らぎ（毎回）: 基音 ±0.35%（約 ±6 セント）、倍音比 ±0.6%、倍音の大きさ ±20%、T60 ±10%、全体 ±1 dB、対の分裂幅、ノイズの読み出し位置。
- 部分音の合計 ＋ ノイズ ≤ 1（単体で確認）。ナイキストの 0.45 倍を超える倍音は捨てる。途中で止めるときは 10ms で絞る（`fadeOut`）。

### ぽぺん（`src/core/audio/pop.ts` が合成、`src/audio/popen.ts` が音型）

- 1つの「ぽん」: 目標の音より 3.5〜6% 高く始まり τ 3 ms で音へ落ちる正弦波（膜が戻る）＋ 薄い殻の倍音（× 2.83、明るさ比例）＋ 約 1 ms のクリック（2.5 kHz ハイパスのノイズ）。
- `pair`: 1音目「ぽ」は控えめで短い（大きさ ×0.7、明るさ 0.25、T60 0.12 s）、2音目「ぺん」は明るく尾が長い（×1、0.5、0.28 s）。
- 4種の音型:

  | 種類 | 音 | 間隔 | 形 |
  |---|---|---|---|
  | 覗く | B5 → B5 | 130 ms | 同じ高さ（玩具そのものの「ぽぺん」。いちばん多く鳴る音） |
  | 置く | D6 → A5 | 120 ms | 4度下がる（落ち着く） |
  | 拾う | A5 → D6 | 90 ms | 4度上がる、速め（持ち上げる。置くの鏡） |
  | 震える | A5 B5 を6回交互 | 55 ms | 小さく（0.28）、1音ごとに ×0.85 で消える |

- 揺らぎ: 時刻 ±5 ms、音程 ±0.2%、大きさ ±1 dB、T60 ±10%。全体の長さは 0.5 秒以下（震えるは約 0.36 秒）。

### 残響（`src/core/audio/reverb.ts`）

- 合成 IR: ステレオの独立ノイズ × exp(−ln1000 · t / T60)。一次ローパスの遮断周波数を 16 kHz から exp(−damping · 6 · t / T60) で下げ、
  分散の減少 a/(2−a) を補正してエネルギーの包絡は T60 に正確に従わせる。プリディレイの後に初期反射。合計エネルギーを 1 に正規化。

  | | T60 | プリディレイ | 戻りの量 | 高域の減衰 | 初期反射 |
  |---|---|---|---|---|---|
  | smallRoom（工房） | 0.6 s | 4 ms | 0.25 | 0.5 | 8本 / 25 ms |
  | largeDome（ドーム） | 4.2 s | 35 ms | 0.45 | 0.65 | 10本 / 120 ms |

- 部屋ごとに ConvolverNode を1つ（buffer は一度だけ）。切り替えはゲインのクロスフェード（0.6 秒）。フェード後の部屋は入力から外す。

### 基盤（`src/core/audio/engine.ts`、`voices.ts`、`mix.ts`）

- 経路: 音 →（Emitter: HRTF PannerNode → フェード用ゲイン）→ バス（音楽 / 効果音 / 環境音）→ 全体 → リミッター → 出力。
  各バスから残響へ送り、残響の戻りは全体へ。
- 音量: スライダー 0..1 → ゲイン = v²。初期値 全体 0.8、他 1.0。走っている間は 30 ms でなめらかに、止まっている間・オフラインは即時。
- 開始: 自分で作ったコンテキストは作成時に止め、最初の操作（pointerdown / pointerup / click / keydown / touchend）で `resume()`。
  ユーザー操作の最中でなければ `resume()` を呼ばない。受け付けは「走っている / オフライン / unlock から 0.25 秒以内」。
- 発音: 上限（全体 48、Emitter ごと 8）では最も小さい音を 10ms で絞って奪う。新しい音は必ず鳴る。
- 位置: 走っている間は `setTargetAtTime`（τ 10 ms）、止まっている間は最新値だけ保持して再開時に反映、オフラインは即時。値が同じなら何もしない。

## 分かったこと

- **Chrome では、JS から参照の切れた経路が、音源が鳴り終わった後の GC で切り離され、残響の尾が途中で切れることがある。**
  1サンプルのインパルスで鳴らした ConvolverNode の尾が不安定に切れた（直す前: 10回中3回失敗、T60 が 0.04〜0.16 s）。
  尾を持つ経路全体（ConvolverNode とその下流）を鳴り終わるまで JS から参照すること。`renderOffline` は描画の間だけ組んだグラフを保持し、
  ライブの `AudioEngine` は残響・バス・Emitter を保持している。
- **ヘッドレスの Chromium（Playwright）は、操作なしでも AudioContext が running で始まる。** 「作成時に止める」処理を外すと e2e (a) が落ちた。
  ブラウザごとの自動再生の差をなくすため、この処理は残す。
- 音は描画経路に依存しないため、WebGPU と WebGL2 で書き出しの数値は一致した。

## 残件

- 耳での確認（上記）。調整値はすべて定数にまとめてある（`glass.ts` の STRENGTH / JITTER、`pop.ts` の ARTICULATION / JITTER、
  `src/audio/popen.ts` の POPEN_PATTERNS、`reverb.ts` の ROOM_PRESETS、`src/audio/tuning.ts` の VIDRO_SIZE_PITCH、`mix.ts` の DEFAULT_VOLUMES、
  `engine.ts` の REVERB_SEND ほか）。
- 録音したガラスの音（設計書「制作方法」）を使う経路はまだない。M1 で合成音と差し替えられる形にする（そのとき基音推定に f/2・f/3 の確認を足す）。
- 環境音のループ、足音、UI の音、生成音楽は範囲外（M1 以降、`src/audio/`）。
- 部屋の IR は初めて使うときにメインスレッドで合成する（ドームは約 37 万サンプル。時間は未計測、以後はキャッシュ）。本編では読み込み中に作っておく。
- AudioContext を作れない環境（音声出力なし等）では `AudioEngine.create` が例外を投げる。本編では無音で続行する逃げ道が要る。
- Safari / Firefox での確認は未実施（Playwright は Chromium のみ）。listener / panner の古い API への切り替えは実装済み。

## 判断待ち

1. **調整値**（設計書に数値がないため仮に決めた。耳での確認後に確定）: 大きさ→音程（直径 10 cm = A5、大きさが倍で1オクターブ下、D2〜D7）、
   工房 T60 0.6 秒 / ドーム 4.2 秒、ガラスの鳴りの長さ（10 cm で 1.6 秒）、強さ3段階の大きさ、音量の初期値（全体 0.8、他 1.0）。
2. **ぽぺんの4種の音型**（覗く B5→B5、置く D6→A5、拾う A5→D6、震える A5/B5 の交互）。設計書は4種があることと「ぽぺん」という音だけを決めている。
3. **技術的な既定値**（設計書の範囲外の実装上の値。変える理由がなければこのまま）:
   同時発音 48・Emitter ごと 8 / 音量曲線 v² / 残響への送り（音楽 0.5、効果音・環境音 1.0）/ 距離減衰（inverse、基準 1 m、最大 100 m、rolloff 1）/
   リミッター（-3 dB、20:1、knee 0、attack 2 ms、release 150 ms。仕様上の自動の持ち上げ（約 +1.7 dB）が入る）/
   unlock 後の受け付けの猶予 0.25 秒 / Emitter を外すときの絞り 15 ms・横取りの絞り 10 ms / 位置のなめらかさ τ 10 ms・音量 τ 30 ms /
   揺らぎの幅（ガラス: 基音 ±0.35%、倍音比 ±0.6%、倍音の大きさ ±20%、T60 ±10%、±1 dB。ぽぺん: 時刻 ±5 ms、音程 ±0.2%、±1 dB、T60 ±10%）。
4. **最初の操作より前の自動再生**: 自動再生が許される環境（ヘッドレスの Chromium など）でも、作成時に止めて最初の操作で始める方針にした。
   設計書の読み込み画面の説明に沿っていると考えるが、確認したい。
