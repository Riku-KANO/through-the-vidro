## 作り

設計書の該当節: サウンドデザイン > 環境音（3D 空間に配置し HRTF、空間の広さに合わせた残響）、音階の統一（環境音も D メジャー・ペンタトニック）、
ガラスの音（大きい物ほど低く）、制作方法（足りない音はシンセサイザーで補う）。世界観とストーリー > 語り口（寂しさではなく見つける喜び、まだそこで暮らしている気配）。
設計書に炉の音・扉の風鈴の数値はない。下の数値はすべて仮（耳で詰める）。

```
PROLOGUE_AMBIENCE（sound.ts）── 場所ごとに環境音の系統の Emitter（HRTF、inverse 1/d、1m まで一定）
  wind:skylight / wind:door / wind:edge     … S-22 のまま
  fire:furnace   FURNACE_MOUTH              … 炉のループ（新規、'fire'。風と同じ「床」で、最初から鳴り続ける）
  chimes:door    WIND_CHIME                 … 扉の上の風鈴（新規）。draught: 'wind:door'、自分の乱数の流れ
  chimes:town    門の向こう                  … S-22 のまま
  drops:skylight / drops:lamp               … S-22 のまま
  drops:tub      TUB_DRIP（水桶の水面）       … S-22 の drops:bucket を移した（音は同じ、D5〜A5）
AmbiencePlayer（ambience.ts）
  start: 床（風・炉）のループを始める。update: 風鈴・水滴・吹き込みを 0.25 秒先まで置く
  吹き込み: 扉の風のループの大きさを ×1.7 に上げ（0.6 秒）、保ち、戻す（1.5 秒）。保っている間に扉の風鈴を打つ
```

### 炉の燃える音（受け入れ条件1）

`renderFurnace`（`src/audio/ambience.ts`）。`FURNACE_SOURCE = synth('furnace-loop', renderFurnace, { sampleRate: 24000 })`、録音への差し替えは S-22 の手順と同じ表の1行。

| 部品 | 中身 |
|---|---|
| 唸り | 雑音を 170Hz と 320Hz の低域通過に2段。炉の奥のゴーという低い音 |
| 胴の鳴り | 同じ雑音を D2（73.4Hz）と A2（110Hz）の狭い帯域通過（Q30）に。炉の空洞が音階の根音と5度でうなる（音階の統一） |
| 炎の息 | 別の雑音を 420Hz の帯域通過に、9.4Hz で揺らす（炎のはためき） |
| 息づかい | 全体の強弱を 2・5・11 周期/ループの正弦の和でゆっくり（±25% 程度） |
| 仕上げ | 全体を 900Hz の低域通過に2段（1kHz より上に何も出さない）。7 秒の継ぎ目のないループ（風は 8 秒なので揃って息をしない） |

- 置き場所は `FURNACE_MOUTH`（S-24 の炉の口の火 `A0_fire` の中心から 8cm 以内、S-24 の単体）。大きさ 0.28（仮）。近づくと大きいのは距離（1/d）だけで決まる。
- 単体: 継ぎ目なし、0.5 秒ごとの強さが最大の半分より下がらない、500Hz より下に力の 9 割、1kHz より上（4次の高域通過）が 3% 未満、
  胴の鳴りの音（±1% の帯域）が半音隣（音階の外）より 1.8 倍以上。

### 扉の上の風鈴と吹き込み（受け入れ条件2）

- **鈴**: S-24 が描いたのは透明ガラスの鈴1つ（直径 8.3cm、肉厚 2.5mm、ガラスの舌、`make_workshop.py` の `wind_chime`）。音はゲームのガラスの規則
  （`glassPitch`、大きい物ほど低く、S-09）で描かれた大きさから決めた **B5（83、987.8Hz）**。遠くの風鈴（D6 E6 F#6 A6 B6）のどれでもなく、どれよりも低い。
- **遠くの風鈴との違い**: 5つの鈴の組ではなく鈴1つ・1音。肉厚なので鳴りが短い（t60 約 1.0〜1.6 秒、遠くは 2.3 秒）。舌がガラスなので当たりが鋭い。
  手吹きの縁のゆがみで、基音の対になるモードが 0.4〜0.7% 上にあり、毎秒 4〜7 回うなる（揺れる「チリン」）。舌が縁に当たって跳ね返り、50〜120ms 後に
  弱くもう1〜2回鳴る。打ち方は4つ（かすめる・叩く2・振り切る）、`DOOR_CHIME_SOURCES`。
- **扉から入る風で、ときどき**: 吹き込みは 8〜18 秒おき（最初は 2.5〜6 秒後）。来るたびに扉の風（S-22 の `wind:door` のループ）の大きさが ×1.7 に
  0.6 秒で上がり、0.8〜1.8 秒（少なくとも最後の打ちの 0.25 秒後まで）保ち、1.5 秒で戻る。風鈴は吹き込みの始まりから 0.25〜0.6 秒後（空気が鈴に届く）に
  鳴り始め、1〜3 回振れる（0.45〜1.1 秒おき、少しずつ弱く）。風鈴は吹き込みの間にしか鳴らない（単体と e2e で確かめる）。
- 置き場所は `WIND_CHIME`（鈴の中心）。大きさ 0.4（仮）。
- **自分の乱数の流れ**: 扉の風鈴の時刻は、種と id のハッシュから作った自分の流れで決める（`AmbiencePlace.rng`、`AmbientSpot.ownStream`）。
  共有の流れを使うと、場所を1つ足しただけで S-22 の音の時刻が全部変わり、種を決めた描画（耳の確認と S-22 のセンサー）が別の物になるため。

### 水桶の雫（受け入れ条件2）

- `TUB_DRIP`（`layout.ts`）: 水桶の縁に掛けた真鍮の柄杓（`make_workshop.py` の `water_tub`: 桶の中心から部屋の中心へ 0.08m、その右へ 0.03m）の真下の水面
  （1.42, 0.36, 1.77）。濡れた柄杓から水へ落ちる、使ったばかりの気配。音は S-22 の水桶の滴（D5〜A5、`notes [0,1,2,3]`）のまま。
- S-22 の `drops:bucket`（1.35, 0.45, −0.5）は真鍮の格子の真上で、何も描かれていない所で鳴っていた（S-24 の残件）。id を `drops:tub` に改めた。

### 観測口とオフラインの描画

- `sceneProbe.sound.ambience` に足した: `places`（場所ごとの id・種類、**PannerNode から読み戻した位置**、panningModel）、`hits`（最新64の打ち）、
  `draughts`（最新16の吹き込み: 始まり・保った終わり・戻った時刻）。`levels` に `fire`。
- `render(spec)`: `bank` に `'fire'`・`'door-chime'`、`ambience` の `at` を全スポーンに、`only`（指定した場所だけを鳴らす）を足した。結果に `draughts`。

扉は `&spawn=door`。ヘッドホン推奨（炉の胴鳴りの D2・A2 はノートの内蔵スピーカーでは聞こえない）。音だけを比べるときは e2e が書き出す WAV
（`artifacts/S-25/wav/`、WebGPU の実行のとき）: `fire-loop-x2.wav`（炉のループ2周、継ぎ目）、`fire-at-<furnace|bench|path>.wav`（炉だけをその場所で）、
`door-chime-<1..4>-<打ち方>.wav`、`door-draughts-45s.wav`（扉に立って、扉の風と風鈴だけ）、`ambience-<furnace|door|bench>-30s.wav`（その場所で全部）。

1. **炉の音の質**: 「低く燃える」に聞こえるか（ゴーという唸りと炎の息、ゆっくりした強弱）。7 秒の繰り返しが分かってしまわないか。胴の鳴り（D2・A2）が
   うなりとして心地よいか、こもって聞こえるか。薪のはぜる音のようなパチパチは入れていない（下の判断待ち2）。
2. **炉の大きさ**: 作業台では風の床より少し下（炉だけで −38dBFS、全体の床 −34）、炉の前で −34、格子の上に立つともっと大きい。目覚めたとき右から
   火の気配がするか。大きすぎて工房が「機械の音」にならないか。
3. **扉の風鈴が遠くの風鈴と別の鈴に聞こえるか**: 低い B5 の1つの鈴、短めの鳴り、毎秒 4〜7 回の揺れ、舌が跳ねるチリン。揺れが強すぎて濁らないか。
   遠くの風鈴（B6 を含む）とオクターブの関係になる音があるが、気にならないか。
4. **扉の風鈴の頻度と大きさ**: 8〜18 秒おき。作業台では遠くの風鈴より山が約 2.5dB 大きいだけ（遠くの風鈴は S-22 で 26m 先から聞こえるように大きさ 2 に
   上げてある）。近さは今は大きさと HRTF の方向だけで聞かせている（残響は系統から送るので、直接音と残響の割合は距離で変わらない。残件）。
   扉の真下（`spawn=door`）では全体の山が −9dBFS（頭のすぐ上の鈴、
   ぽぺんの −10 と同じくらい）。作業台で「近くの鈴」に聞こえるか、扉の下でうるさくないか（判断待ち3）。
5. **吹き込み**: 風鈴の直前に扉の風がふくらむ（+4.6dB、0.6 秒）のが「扉から風が入って鈴が鳴った」と聞こえるか。分からなければ ×1.7 を上げるか、
   吹き込みに風鈴以外の音（短冊が揺れるかすかな音など）を足すか。
6. **水桶の雫**: 作業台から見て右奥（炉の向こう、マーバー台の左）の水桶から、低め（D5〜A5）の滴。S-22 では炉の前の格子の上で鳴っていた。方向が描かれた
   水桶と合って聞こえるか。
7. **暮らしている気配**: 炉の火・使ったばかりの柄杓の雫・扉の風鈴で、工房が「さっきまで誰かがいた」場所に聞こえるか。何が足りないか。

## 判断待ち

1. **炉の音を入れること自体と、その中身・大きさ**: 設計書の環境音（風・遠くの風鈴・水滴・雨）にない音。S-22 の判断待ち5の提案を spine の S-25 が採った。
   今は唸り＋胴の鳴り（D2・A2）＋炎の息。大きさ 0.28（作業台で風の床の下、炉の前で前に出る）。
2. **薪のはぜる音（パチパチ）を足すか**: 吹きガラスの炉はガスや油で焚き、ゴーという唸りが主なので入れていない。入れるならループに入れず（7 秒で繰り返しが
   分かる）、水滴と同じ一度きりの音を予定表で鳴らす。
3. **扉の風鈴の音と大きさ**: 描かれた大きさからゲームのガラスの規則で B5。本物の江戸風鈴は薄くて規則より高く鳴るので、高い音（D6 以上）にする案もあるが、
   遠くの風鈴の音と重なる。大きさ 0.4: 作業台では遠くの風鈴より山が 2.5dB 大きいだけ、扉の真下では全体の山 −9dBFS。上げると扉の下でうるさく、
   下げると作業台で遠くの風鈴と区別がつきにくい（近さの手がかりが大きさと HRTF だけのため。残件1）。
4. **吹き込みの強さと間**: 扉の風を ×1.7（+4.6dB）、8〜18 秒おき。吹き込みごとに必ず風鈴が鳴る（鳴らない吹き込みは作っていない）。
5. **炉の音の揺らぎを炉の灯りと揃えるか**: S-24 の炉の点光源は ±8% でゆっくり揺らぐ（`room-art.ts`、S-27 の範囲）。音の息づかいは自分の周期で、光と
   揃っていない。揃えるなら、揺らぎの時刻の関数を1つにして両方が読む（S-27 と調整）。

## 残件

1. **近さの手がかりが大きさと HRTF だけ**: エンジン（`src/core/audio/engine.ts`）は Emitter を系統へ送り、系統から残響へ送るので、直接音と残響の割合が
   距離で変わらない。近い扉の風鈴も遠い風鈴も同じ割合で響く。Emitter ごとに距離で残響への送りを変える仕組みは core の変更（案2と共有）なので、
   残響のスライスで扱う（S-25 では core を変えていない）。
2. 炉の音は工房の外（一本道・向こう岸）でも距離だけで弱まる。ドームのガラスの遮りはない（S-22 の音も同じ）。
3. 録音への差し替え（S-22 の手順のとおり表の1行）: 炉のループ（`FURNACE_SOURCE`。ループなので AAC にしない）、扉の風鈴の4つの打ち方
   （`DOOR_CHIME_SOURCES`。B5 に揃える。舌の跳ねは予定表が作るので、録音は1打ずつ）。
4. 主スレッドでの合成の重さ: 炉のループ（24kHz、7 秒）は Node で約 6〜10ms、扉の風鈴は1つ 1〜2ms。実機では測っていない（S-22 の残件と同じ）。
5. 観測口の `levels.chimes` は遠くの風鈴と扉の風鈴をまとめて聞く（種類ごとの耳）。どちらが鳴ったかは `sources`・`hits` の id で分ける。
6. 遠くの風鈴・水滴（S-22 の音）は今も1本の乱数の流れを共有している。足した扉の風鈴だけが自分の流れを持つ。全部の場所を自分の流れにするのが筋だが、
   そうすると S-22 の種を決めた描画（耳の確認の WAV、S-22 の e2e）が別の物になるので、S-22 の e2e を直すときに一緒に移す（提案2）。
